# 1. Levantamento prévio de requisitos

O que o cliente disse, **cru**. Este nível não organiza nem decide: ele registra.

## O que entra

| Arquivo | Conteúdo |
| :--- | :--- |
| `000 - fontes.md` | De onde veio cada informação: quem falou, quando, em que reunião |
| `001 - objetivos.md` | O que o cliente quer que mude na operação dele |
| `002 - servicos-ofertados.md` | O que o negócio vende, na linguagem dele |
| `003 - descricao-dos-servicos.md` | Cada serviço em detalhe: quem faz, em que ordem, o que trava |
| `004 - entidades.md` | Os substantivos do negócio, com os atributos que apareceram na conversa |
| `005 - requisitos.md` | A primeira lista, ainda desorganizada |
| `desenho/` | Diagramas (`.excalidraw`), fotos de quadro branco, prints de planilha |

## Duas regras

**Não interprete aqui.** Se o cliente disse "a gente às vezes pula essa etapa", escreva isso — não
"a etapa é opcional". A primeira é fato, a segunda é decisão, e decisão é do nível 2.

**Registre a fonte de cada afirmação.** Seis meses depois, a diferença entre "o cliente disse" e
"alguém supôs" é o que decide uma discussão.
