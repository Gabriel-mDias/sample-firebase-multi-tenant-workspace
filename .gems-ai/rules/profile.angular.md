# Angular profile

Features MUST remain self-contained, strictly typed, standalone, and route-owned. State and forms
MUST expose loading, error, empty, and success behavior. Authorization MUST mirror the concrete API
action and fail closed. Components SHOULD use GEMS equivalents when contracts match and MUST meet
applicable accessibility requirements. Clean install, formatting, unit tests, route tests, and the
production build are required gates.
