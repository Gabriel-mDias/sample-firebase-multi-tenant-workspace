# Workspace integration

Cross-layer changes MUST identify the shared contract, migration order, compatibility window,
environment impact, rollback, and a gate on each side of the boundary. Published SDK coordinates
and generated snapshots MUST be locked. A green component gate MUST NOT substitute for the complete
workspace gate at closure.
